GoBot

Robotics club engineering project

Role: Club project contributorOngoingStatus: Active
RoboticsClubHardwareSoftware

Overview

GoBot is a robotics club project focused on building and iterating on a mobile robot platform. The project combines mechanical design, electronics, and software in a collaborative student environment.

Objectives

  • Develop a functional mobile robot base
  • Integrate sensors, actuators, and control software
  • Practice systems integration and team engineering processes

Scope

Typical activities include:

  • Chassis and mechanical design
  • Motor control and power systems
  • Sensor integration
  • High-level behaviour and navigation software
  • Testing and iterative improvement

Technologies

  • Embedded controllers and motor drivers
  • ROS / ROS 2 or equivalent middleware (as used by the club)
  • CAD for mechanical design
  • Standard robotics sensors (encoders, distance, cameras, etc.)

Outcomes

The project provides practical experience in end-to-end robot development and collaborative engineering. Specific technical results and media will be added as they become available.
